## Scientific and deployment boundaries

Station loading is not a global ocean-height atlas. Convex uniform-density
fracture is not a calibrated material crack model. The complete Wasm source
runner is an interpreter, not a native C/Rust engine; it is slower in measured
cases and remains optional. These boundaries are visible in the labs and README.

No physical-device certification, participant learning outcomes or hosted-origin
verification is claimed. After linking Cloudflare Pages, follow
[the live deployment checks](deployment.md). No gameplay server is required.
