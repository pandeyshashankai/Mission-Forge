# Recorded release audit

Generated by `npm --prefix frontend run audit:release -- --extended`.

[The manifest](manifest.json) identifies the tested build and all 25 passing
audit groups. Each named JSON file records its command, duration and result.
The generated `.log` transcripts remain available locally and are ignored by Git.
The source tree was uncommitted; the manifest explicitly records that state.

Tests cover stated finite matrices and emulated Chromium workflows. They do not
certify arbitrary rockets, every physical device or real-world flight accuracy.
See [storage contracts and remaining release work](../../serverless-readiness.md).
