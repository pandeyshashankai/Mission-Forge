# Recorded release audit

Generated by `npm --prefix frontend run audit:release -- --extended`.

[The manifest](manifest.json) identifies the clean implementation commit and
tested build, with all 30 passing audit groups. Each JSON file records the
command, duration and outcome; the corresponding `.txt` file contains its
complete output. The source runner generates `.log` files; the published copy
uses `.txt` so transcripts are reviewable on GitHub.

The evidence commit follows the tested implementation and changes documentation
and validation records only. Build asset hashes were rechecked before publication.
Tests cover finite matrices and emulated Chromium workflows, not every possible
trajectory, physical device or real-world accuracy claim.
